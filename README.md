# Moaz Elborollosy | Mechatronics Engineering Portfolio

I’m a Mechatronics Engineering student in Berlin interested in robotics, automation, mechanical design, and software development. This website presents my projects, technical skills, education, and CV in one place.

## Featured Projects

| Project | Focus | My Work |
| --- | --- | --- |
| Custom Quadcopter Drone | Mechanical design | Designed the SolidWorks assembly and checked component clearances with motion studies. |
| Robotic Gripper | Mechanism design | Built a linkage-driven assembly and configured kinematic mates for grasping motion. |
| Embedded Robotic Arm | Robotics and control | Designed the arm in SolidWorks and wrote Arduino C++ logic for coordinated servo movement. |
| Active Low-Pass Filter | Electronics | Designed and simulated a circuit to attenuate high-frequency noise. |
| [Assembly Interpreter](https://github.com/moazelborollosy/Assembly-Interpreter) | Java | Built instruction parsing and execution for a simulated CPU. |

## Website Features

- Responsive design for desktop and mobile.
- Animated network background that moves automatically.
- Project filters and expandable project details.
- Downloadable CV and links to my GitHub and LinkedIn profiles.
- Transparent portrait integrated with the website background.
- Reduced-motion support for visitors who prefer less animation.

## Built With

React · TypeScript · Vite · Tailwind CSS · Framer Motion · Lucide Icons

## Run Locally

From the root of the repository:

```bash
cd moaz-engineering-portfolio
npm ci
npm run dev
```

Open the local address shown in the terminal. To create a production build, run:

```bash
npm run build
```
